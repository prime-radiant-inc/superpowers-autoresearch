# calc

A tiny calculator library with a pytest test suite.

## Running tests

```
pytest
```

Useful flags we use day to day:

- `-k EXPR` — only run tests matching EXPR
- `-x` — stop after the first failure
- `-v` — verbose output
- `--maxfail=N` — stop after N failures

## Layout

- `calc.py` — the library
- `test_calc.py` — the test suite
